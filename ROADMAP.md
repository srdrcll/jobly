# 🗺️ Kariyer Pusulası — Product Roadmap

This document outlines the strategic vision, completed milestones, and upcoming feature roadmap for **Kariyer Pusulası (Candidate-Centric ATS & CRM SaaS)**.

---

## 🎯 Released Milestones

### ✅ Version 0.5.0 — Dashboard & Analytics Release
- Real-time KPI summary cards (Total Applications, Active Applications, Interviews, Offers, Rejections, Success Rate %).
- Interactive Recharts analytics (Status Distribution Donut, 6-Month Activity Bar Chart, 7-Day Pace Line Chart).
- Responsive mobile & desktop layouts.

### ✅ Version 0.6.0 — Company Management & Candidate CRM Release
- Company Directory (`/companies`) & Dedicated Profiles (`/companies/:id`).
- Recruiter Networking & Interaction Logger (Recruiter Messages, Emails, LinkedIn connections, Phone calls).
- Pinned Rich Text Notes & Company-specific follow-up tasks.
- Bulk selection toolbar (Archive, Restore, Favorite, Delete).

### ✅ Version 0.7.0 — Interview Management & Interactive Calendar Release
- Scheduled Interview Manager (`/interviews`).
- Interactive Month Grid Calendar with date navigation and event modals.
- Preparation Toolkit (Interactive checklists, company research, role expectations, technical topics).
- Post-Interview 5-Star Self-Evaluations (Overall, Technical, Communication, Confidence).
- Live Next Interview Countdown Banner.

### ✅ Version 0.8.0 — AI Career Assistant & Review Suite Release
- Provider-Agnostic AI Assistant (`/ai-assistant`) with Gemini, Claude, and GPT-4o adapter architecture.
- AI Resume Review & 0-100 ATS Scoring Engine.
- AI Cover Letter 6-Dimension Evaluation.
- AI Interview Simulation Coach & STAR Answer Evaluator.
- Personal Career Conversion Insights & Automated Goal Tracker.

### 🚀 Version 1.0.0 — Public Production Release (Current)
- Complete production audit score (100/100).
- Enterprise-grade Supabase RLS data isolation.
- Full keyboard accessibility & dark mode glassmorphism UI.
- Comprehensive end-to-end documentation & deployment guide.

---

## 🔮 Future Roadmap (Post v1.0.0)

### 📦 Phase 2: Document Center & CV Versioning (v1.1.0)
- Multi-CV version control & PDF preview modal.
- Document attachments per application (Cover letters, Portfolios, Offer letters).
- Auto-extract CV text using WebAssembly PDF parsers.

### 🔔 Phase 3: Push Notifications & Browser Reminders (v1.2.0)
- Web Push Notifications for interview countdowns and follow-up tasks.
- Google Calendar & iCal calendar export (.ics downloads).

### 🌐 Phase 4: Job Board Aggregator Integration (v1.3.0)
- Chrome Extension for 1-click job application saving from LinkedIn, Indeed, and Kariyer.net.
- Automated email parsing for application status updates.
